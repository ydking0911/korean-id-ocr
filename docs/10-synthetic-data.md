# 10. 합성 신분증 데이터 계획 (4단계 평가용)

참고: 케이뱅크 기술 블로그 「신분증 OCR 모델 학습을 위한 가상 데이터 생성하기」(2023-12-15, kbank-recruit.tistory.com/74)

## 1. 블로그 요약

| 단계 | 방법 |
|---|---|
| 1. 템플릿 | 신분증 촬영 → 카드 영역 crop → 텍스트 영역 마스크 이미지 제작(이미지 편집기) → **PyInpaint**(PDE 기반 inpainting)로 글자 제거 → 빈 배경 템플릿. 지운 흔적은 약간 남음 |
| 2. 가상 정보 | 항목별 txt 목록. 이름(한글·한자)·발급기관은 ChatGPT, 주소는 공공데이터, 번호·날짜는 패턴 + 랜덤 |
| 3. 합성 | **TextRecognitionDataGenerator(trdg)**를 수정해 지정 좌표에 텍스트를 그림. 항목을 하나씩 **누적 합성**하며 매번 이미지 + 레이블(단어 4점 박스 + 텍스트, 글자 단위 박스) 생성 |
| 항목 수 | 주민등록증 6개(이름 한글·한자, 주민번호, 주소, 발급일자, 발급기관), 운전면허증 10개(이름, 면허번호, 주민번호, 면허종류, 주소, 갱신 시작·종료일, **보안코드 6자리**, 발급일자, 발급기관) |
| 값 정합성 | 길이·형태 패턴만 맞춤. 주소–발급기관 불일치, 적성검사기간 오류 등 무효 값이 많지만 검출·인식 **학습** 용도라 무시 |
| 라이선스 | 글·이미지 **CC BY-NC-ND 4.0** (비영리, 변경 금지) |

## 2. 우리 목적과의 차이

블로그는 **검출·인식 모델 학습**용이고, 우리는 파인튜닝을 하지 않으므로 **구조화 파이프라인 평가**용이다. 그래서 몇 가지를 다르게 한다.

| 항목 | 블로그 | 우리 |
|---|---|---|
| 값 정합성 | 무시 | **유지** — 날짜 순서·유효기간·주민번호 생년월일 검증 로직을 평가해야 하므로 값이 그럴듯해야 함 (발급일 ≥ 출생일+17년, 적성검사 시작 ≤ 종료 등) |
| 레이블 | 단어·글자 박스 | **필드 단위 정답 JSON**(`*.gt.json`, 05 문서 스키마와 같은 키) + 필드 박스 |
| 합성 도구 | trdg 수정 | **PIL로 직접 렌더링** — 필드 좌표만 지정하면 되므로 trdg 의존성·수정 불필요 |
| inpainting | PyInpaint | **OpenCV `cv2.inpaint`** (이미 의존성에 있음). 품질 부족 시 PyInpaint 검토 |
| 블로그 이미지·템플릿 | — | **재사용하지 않음** (CC BY-NC-ND). 방법만 참고 |

## 3. 우리 파이프라인 (초안)

```
samples/specimen/*.png (홍길동 견본, 박스 없는 원본)      ← gitignore
        │  필드 영역 = 사용자가 공유한 파란 박스 위치 (템플릿별 좌표 JSON으로 기록)
        ▼
① 템플릿 생성: 필드 영역 마스크(여백 dilate) → cv2.inpaint
   + 자동 검증: 템플릿에 OCR을 돌려 필드 영역에서 글자가 검출되면 실패
     (지운 흔적이 남으면 정답에 없는 글자가 생겨 평가가 오염되므로)
        ▼
② 가상 값 생성: 가짜 이름(성+이름 조합), 주민번호(유효 날짜, 뒷자리 랜덤),
   주소(행정구역 목록 + 도로명 패턴), 발급기관(주소의 시·군·구와 일치),
   면허번호(지역코드 표), 보안코드(영대문자·숫자 6자리), 날짜(정합성 유지)
        ▼
③ 렌더링: 필드 좌표·폰트 크기·색은 템플릿 JSON에서. 폰트 여러 종 랜덤
   → image + gt.json (필드 값 + 필드 박스)
        ▼
④ 촬영 조건 변형 (08 문서 분류 채택):
   angle(원근) / rotated(90·180·270 + 소각도) / bright(밝기·대비·그림자) / blur·jpeg /
   occluded(손가락·반사 하이라이트) / background(책상·천 배경 합성) / near·far(크기)
        ▼
samples/synthetic/<조건>/<id>.jpg + <id>.gt.json                    ← gitignore
```

- 생성 스크립트는 `tools/synth/`에 커밋, 이미지·템플릿·폰트는 커밋하지 않음.
- 견본 이미지 자체의 저작권 확인 필요 (출처가 공공기관 견본이면 출처 표기).
- 시드 고정으로 재현 가능하게. 평가셋과 개발 중 확인용 셋은 시드를 분리.
