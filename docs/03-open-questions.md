## 남은 질문

### Q1. status 판정 규칙 (05 문서 6절)
- 단일 임계값으로 바로 FAIL 대신 **OK / PARTIAL / FAIL 3단계**를 유지할지
- 핵심 필드 정의: 주민등록증 `name`·`rrn`, 운전면허증 `name`·`rrn`·`license_number`
- 초기 임계값: 숫자 0.90 / 텍스트 0.85 / 주소 0.80 (평가 하네스로 재조정)
